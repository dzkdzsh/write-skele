# 文风词表

扫描用的词在这里，规则与对照在 `文风细则.md`。新增词只改本文件，`scripts/style_scan.py` 自动读取。

格式约定：每条以 `- 类别：` 开头，词之间用顿号分隔，括号说明不参与扫描。分两类：

- **硬禁**：这些词在学术正文里没有正当用法，命中即改。
- **提示**：命中后由人判断。断言层的词大多有合法用法（「节点数决定面积」不是过度断言），全当错误会淹没真问题。

单字词不自动扫描，列在最后一节。

## 一、商业与生活隐喻（硬禁）

- 记账：算账、一笔账、买单、回本、划算、不划算、算不过来
- 交易：性价比、买卖、投资回报、红利、分红、护城河
- 消耗：吃掉、吞掉、啃下、抢占、蚕食、榨干
- 极限：天花板、雪球、滚雪球、触顶
- 夸张：魔法、黑魔法、放大招、杀手锏、玩具、毒瘤、温床、救火

## 二、口语与随意表达（硬禁）

- 主观表述：我觉得、我认为、我们觉得、在我看来、个人认为
- 交际提示：大家都知道、我们知道、你看、你想想、不难看出
- 简化动词：搞定、搞清、弄明白、跑一遍、算一下、看一看、凑一凑
- 泛化指代：这个东西、那个东西、这些事、之类的东西、那一套
- 评价程度：挺好、不错、很棒、很糟、超级
- 网络流行语：拉满、赋能、抓手、颗粒度、对齐、打法、复盘、闭环、破防

## 三、讲解口吻与元话语（硬禁）

- 引导：我们来看、先看一个例子、这里有个技巧、下面我们
- 强调：值得注意的是、值得一提的是、值得单独说明、需要强调的是、必须指出
- 断言腔：恰恰、本质上、归根结底、说白了、说穿了、换个角度想
- 套话：综上、由此可见、不难发现、众所周知、显而易见、一言以蔽之
- 设问：为什么呢、答案在于、何以如此

## 四、需人工判断（提示）

- 模糊限定：可能、也许、大概、好像、似乎、差不多、左右、基本上、大致
- 模糊数量：很多、好多、一些、几个、大量
- 随意连接：然后、还有、所以、但是
- 因果强调：正是、恰恰、正是因为
- 绝对化：完全、彻底、必然、一定、所有、任何、从不、永远、唯一、最优
- 首创性：首次提出、首次实现、填补空白、国内首创、国际领先、业界首次
- 因果越级：导致、决定、证明、充分说明、印证了
- 效应夸大：显著提升、大幅改善、革命性、颠覆性、极大提高、巨大突破
- 外推：可推广至所有、适用于任何、通用性强、放之四海

## 五、单字词（人工看）

- 语气助词：吧、呢、啊、啦、嘛
- 简化动词：搞、弄、整、赚、亏
- 判断词：很、太、挺、蛮

这些字在合成词里大量出现（整体、完整、整理、环境），自动扫描必然误报，只在通读时留意。
