# 文风细则

配合 `AGENT.md` 第 3 节使用。`AGENT.md` 只放高频条目，这一份放完整词表、对照与检查方法。定稿时按本文件逐条扫一遍。

## 一、三层问题

文风失当有三种来源，处理方式不同：

| 层 | 表现 | 处理 |
|---|---|---|
| 判断层 | 用生活经验替代专业判断（算账、划算、吃掉） | 换成术语承载，见第二节 |
| 词汇层 | 口语词、语气词、模糊限定 | 逐个替换，见第三、五节 |
| 断言层 | 措辞强度超过证据（证明、首次、完全） | 降级动词或加限定，见第四节 |

`humanizer` 类技能只覆盖第一层里「AI 腔」那一部分（模板化、空泛、排比、破折号），不覆盖中文口语腔，也不覆盖断言强度。

## 二、商业与生活隐喻

这类词的问题不是不雅，而是把专业判断降格成消费选择，读者会觉得作者在用生活经验代替分析。

| 类别 | 例词 | 改法 |
|---|---|---|
| 记账 | 算一笔账、一笔账、买单、回本 | 定量分析、代价分析、承担代价 |
| 交易 | 划算、不划算、性价比、买卖、投资回报、红利 | 权衡、代价收益比、收益、增量 |
| 消耗 | 吃掉、吞掉、啃下、抢占、挤占 | 占据、消耗、占去、压缩 |
| 极限 | 天花板、雪球、滚雪球 | 上界、下界、累积效应 |
| 夸张 | 魔法、黑魔法、放大招、杀手锏、玩具、毒瘤、温床 | 直接陈述机制，或删去 |

判断技巧：译成英文若出现 accounting、bargain、eat、swallow、buy、sell 一类词，说明这一段写成了生活经验。

## 三、口语与随意表达

1. **语气助词**：吧、呢、啊、啦、嘛、罢了、而已。全部删除，改陈述句。
2. **模糊限定**：大概、可能、也许、好像、似乎、差不多、左右、估计、基本上。改为「约」「在……范围内」，或给出实测值。
3. **主观表述**：我觉得、我认为、我们觉得、在我看来。改为「本文认为」「结果表明」。
4. **交际提示语**：大家都知道、我们知道、你看、你想想。删除，直接给事实。
5. **简化动词**：搞、弄、整、搞定、搞清、弄明白、跑一遍、算一下、看一看。改为开展、构造、计算、检验、识别。
6. **泛化指代**：这个东西、那个东西、这些事、之类的东西。改为具体名词。
7. **评价与程度**：挺好、不错、很棒、很糟、超级、特别、极大、巨大。改为量化，或删去。
8. **随意连接**：句首的「然后」「还有」「所以」「但是」。改为「随后」「此外」「因此」「然而」，或直接断句。
9. **数量模糊**：很多、好多、一些、几个、大量（无数字）。给出数值或比例。
10. **网络与流行语**：拉满、赋能、抓手、颗粒度、对齐、打法、复盘、闭环。全部替换为本领域术语。

## 四、过度断言

措辞强度必须与证据水平对齐。这一类最伤可信度，审稿人一眼能看出。

1. **绝对化**：完全、彻底、必然、一定、所有、任何、从不、永远、唯一、最优。改法：加限定（在本模型参数下、在测试范围内、在多数工况下）。
2. **首创性**：首次提出、填补空白、国内领先、国际首创。中科院科研道德委员会的诚信提醒明确反对这类无佐证表述。改法：只陈述做了什么，不宣称地位。
3. **因果越级**：导致、决定、证明。观察性数据只能用「表明」「提示」「与……相关」；「证明」留给有对照实验支撑的结论。
4. **效应夸大**：显著提升、大幅改善、革命性、颠覆性。改法：给统计量或百分比，并说明基准。
5. **外推**：可推广至所有场景、适用于任何情况。改法：写明适用范围（本研究的样本、工艺、位宽范围）。

## 五、对照表

| 原表述 | 改写 |
|---|---|
| 需要一张定量的账 | 需要给出定量的预算与代价分析 |
| 这样并不划算 | 这一取舍的收益不足以抵偿相应代价 |
| 该方案吃掉大部分收益 | 该方案占据了大部分可得的收益 |
| 性价比最高的手段 | 单位代价收益最高的手段 |
| 面积的天花板 | 面积的下界 |
| 我觉得这个结论有意义 | 本研究结果具备一定的参考价值 |
| 大家都知道这个理论很成熟 | 现有研究共识表明该理论已得到广泛验证 |
| 我找了很多相关文献 | 本研究系统梳理了该领域的已有成果 |
| 这个结果挺有意思 | 该结果呈现出区别于既有研究的特征 |
| 实验结果差不多符合预期 | 结果与预设假设的拟合度较高 |
| 之前没人做过这个研究 | 现有文献尚未针对该维度展开讨论 |
| 但是这个方法有问题 | 然而现有框架仍存在一定局限 |
| 好几组数据都支持这个结论 | 多组实验共同支撑该结论 |
| 一开始找数据找了很久 | 本研究通过多源数据库交叉核验完成数据采集 |
| 这个办法肯定能解决问题 | 该路径对同类问题具备较高的借鉴性 |
| 样本数量挺多的 | 有效样本量满足统计分析的显著性要求 |
| 最后我得到了几个结论 | 基于上述分析可得出如下结论 |
| 本文证明该方法最优 | 在本组参数下，该方法的延迟低于其余方案 |
| 显著提升了性能 | 延迟由 X 降至 Y（基准为 Z） |
| 填补了该领域的空白 | 本文给出该问题的一个可复算的解法 |
| 可以推广到所有场景 | 在本文测试的位宽与工艺范围内成立 |

## 六、检查方法

1. **词表扫描**（防复发，扫不到新造的隐喻）：

```bash
grep -rn -E "算账|一笔账|划算|吃掉|吞掉|买单|性价比|天花板|雪球|魔法|放大招|挺好|不错|大概|差不多|搞|弄|整|我觉得|大家都知道" --include="*.tex" .
grep -rn -E "首次|填补空白|完全|彻底|必然|所有|任何|永远|唯一|证明|革命性|颠覆性|大幅" --include="*.tex" .
```

发现新词就补进这两条命令，同时补进 `AGENT.md` 的高频条目或本文件的表格。

2. **三处必读**。词表扫不到句式，这三处要人读：
   - 每章开头的导读段：最容易写成讲课口吻。
   - 摘要与结论段：最容易出现过断言。
   - 图题与表题：最容易写成「某某随某某变化」这类空话。

3. **强度校准**。见到「证明」「显著」「首次」「完全」，问一句：证据是什么？答不出来就降级。

4. **译英测试**。把可疑段落译成英文，看是否出现口语化表达。译文越像聊天，原文越口语。

## 七、与其他技能的分工

`humanizer-zh` 处理的是英文写作研究里那套 AI 痕迹：夸大象征、宣传腔、-ing 式空泛分析、模糊归因、破折号滥用、三段式。它不处理中文口语腔与断言强度。

所以：开不开它，都不改变本文件的要求。技能是补充，语体责任在规则本身。
