# 文风细则

配合 `AGENT.md` 第 3 节。词表在 `docs/文风词表.md`，扫描脚本是 `scripts/style_scan.py`；本文件讲规则与改写。

## 一、三层问题

| 层 | 表现 | 处理 |
|---|---|---|
| 判断层 | 用生活经验替代专业判断（算账、划算、吃掉） | 换成术语承载，见第二节 |
| 词汇层 | 口语词、语气词、模糊限定 | 按词表替换，见 `文风词表.md` |
| 断言层 | 措辞强于证据（证明、首次、完全） | 降级动词或加限定，见第三节 |

`humanizer` 类技能只覆盖「AI 腔」（模板化、空泛、排比、破折号），三类都不覆盖，别把责任交给它。

## 二、判断层的四条规则

1. **判断由术语承载**。专业判断落在：权衡、代价、收益、约束、余量、边际、上界、下界、比例、数量级、单调、收敛。不落在「划算」「值不值」「亏不亏」上。
2. **比喻不承担判断**。可以有解释性比喻，但只作括注或补充句，主句必须是概念表述。
3. **不用讲解口吻**。写作不是讲课，去掉「我们来看」「说穿了」「本质上就是」这类引导。
4. **译英测试**。译成英文若出现 accounting、bargain、eat、swallow、buy、sell，说明判断写成了生活经验。

## 三、断言层的分级

措辞强度必须与证据水平对齐。同一件事，证据不同，动词不同：

| 证据 | 可用动词 | 不可用 |
|---|---|---|
| 对照实验、消融、随机试验 | 证明、确证、决定 | —— |
| 多组数据一致 | 表明、支持、一致于 | 证明 |
| 单组观察、相关性 | 提示、与……相关、可能源于 | 导致、决定 |
| 模型估算、推理 | 估计、推算、在……条件下成立 | 实测、验证 |

另有三类高危表述：**首创性**（首次提出、填补空白、国际首创），中科院科研道德委员会的诚信提醒明确反对；**绝对化**（完全、必然、所有、唯一），只要有一个反例就得重写；**外推**（可推广至所有场景），必须写明适用范围。

## 四、改写对照

| 原表述 | 改写 |
|---|---|
| 需要一张定量的账 | 需要给出定量的预算与代价分析 |
| 这样并不划算 | 这一取舍的收益不足以抵偿相应代价 |
| 该方案吃掉大部分收益 | 该方案占据了大部分可得的收益 |
| 性价比最高的手段 | 单位代价收益最高的手段 |
| 面积的天花板 | 面积的下界 |
| 我觉得这个结论有意义 | 本研究结果具备一定的参考价值 |
| 大家都知道这个理论很成熟 | 现有研究共识表明该理论已得到广泛验证 |
| 我找了很多相关文献 | 本研究系统梳理了该领域的已有成果 |
| 这个结果挺有意思 | 该结果呈现出区别于既有研究的特征 |
| 实验结果差不多符合预期 | 结果与预设假设的拟合度较高 |
| 之前没人做过这个研究 | 现有文献尚未针对该维度展开讨论 |
| 但是这个方法有问题 | 然而现有框架仍存在一定局限 |
| 好几组数据都支持这个结论 | 多组实验共同支撑该结论 |
| 一开始找数据找了很久 | 本研究通过多源数据库交叉核验完成数据采集 |
| 这个办法肯定能解决问题 | 该路径对同类问题具备较高的借鉴性 |
| 样本数量挺多的 | 有效样本量满足统计分析的显著性要求 |
| 最后我得到了几个结论 | 基于上述分析可得出如下结论 |
| 本文证明该方法最优 | 在本组参数下，该方法的延迟低于其余方案 |
| 显著提升了性能 | 延迟由 X 降至 Y（基准为 Z） |
| 填补了该领域的空白 | 本文给出该问题的一个可复算的解法 |
| 可以推广到所有场景 | 在本文测试的位宽与工艺范围内成立 |

## 五、检查方法

1. **词表扫描**：`python scripts/style_scan.py`，命中即退出码 1，可接在提交前。词表更新只改 `文风词表.md`，不必改脚本。
2. **三处必读**。词表扫不到句式，这三处要人读：
   - 每章导读段：最容易写成讲课口吻。
   - 摘要与结论：最容易出现过度断言。
   - 图题与表题：最容易写成「某某随某某变化」这类空话。
3. **强度校准**。见到「证明」「显著」「首次」「完全」，问一句：证据是什么？答不出就降级。
4. **单字词人工过**。吧、呢、整、搞、挺、太这类词表不扫（误报太多），通读时留意。

发现新词，先加进 `文风词表.md`，再判断是否要写进 `AGENT.md` 的高频条目。
